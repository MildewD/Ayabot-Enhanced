# Ayabot

**完全免费**的超轻量 B 站直播间弹幕机器人。签到抽签、盲盒统计、AI 对话、自动欢迎/感谢、定时消息、Web 后台管理，一应俱全。
开箱即用，小白友好。纯 Python 跨平台，无需 systemd / sudo。

> ⚠️ **免责声明**：本项目为个人非商业开源项目，所调用的接口、内容与素材均来自第三方公开渠道，与哔哩哔哩（bilibili）官方无关，亦未获其授权或背书。如权利人认为存在侵权，请通过 [Issues](https://github.com/yujianke100/Ayabot/issues) 联系作者，核实后立即修改或下架。

## ✨ 本版本更新内容

基于原版 Ayabot 深度定制增强，主要更新如下：

### 🎨 Web 后台界面重做
- **浅色极简玻璃拟态现代风**：全站毛玻璃（backdrop-filter）、柔和渐变、统一圆角，彻底取代默认皮肤。
- **夜间模式**：顶栏一键「☀️ / 🌙」切换，背景/文字/卡片/弹窗全适配，选择自动记忆（localStorage）。
- **全站细节美化**：登录页玻璃拟态 + 渐变背景；顶栏悬浮玻璃条、胶囊导航；房间列表玻璃卡片（运行/停止两态、状态徽章、柔和操作按钮）；新建房间表单、页面标题、弹窗（玻璃化 + 毛玻璃遮罩 + 入场动画）、细滚动条、帮助页命令表格等逐一精修。

### 💬 弹幕记录增强
- **关键词搜索 + 高亮**：实时过滤弹幕。
- **用户 / UID 筛选 + 统计面板**：按观众快速定位发言与送礼。
- **按场次查看整场弹幕**：自动按时间间隔切分录像场次，一键回看。
- **录像对应时间显示**：弹幕自动关联到对应录像时间点，方便复盘。
- **可搜索的场次选择面板**：工具区分组排版，进场自动加载场次。

### 🖼️ 精美导出
- 界面前所未有的清晰布局。
- 支持按用户合并、显示金额开关、日间/夜间主题自适应。
- 修复生成后大航海徽章 / 头像缺失（兼容新协议解析 + 上舰数据兜底）。
- 修复日期选择日历被卡片遮挡的问题（Vue Teleport 渲染到顶层 + 夜间配色）。

### 🔧 稳定性与功能
- 修复多实例重复欢迎：新增房间级跨进程互斥锁，同一房间仅允许一个 Bot 实例运行。
- 修复 PK 主动结束状态复位。
- 新增 `run_when_not_live` 开关（未开播时是否运行）。
- 老版本数据可**无损迁移**至本版本。
